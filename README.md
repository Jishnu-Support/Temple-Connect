# Temple Connect

Temple Connect helps devotees find temples, priests, timings, special events and festival days, in English and Tamil.

## Features
- Temple directory with search, and a nearby temples list based on your location
- Temple details: priest, management (common, trust or community), location pin, special event, major events and history
- Daily timings for each day of the week, plus changes for particular dates
- Event calendar with Amavasai, Pournami, Sankatahara Chaturthi, Ekadasi, Pradosham, Karthigai and Sashti, with approximate tithi and moon rasi timings
- Temple news, past news, and photos and videos by event
- Separate logins for temples, common users and the company
- Duplicate temple check, English and Tamil

## Run it
This is a single-file prototype. Open `index.html` in a browser.
All data is stored in the browser (localStorage and IndexedDB). There is no server or database yet.

Demo logins (password `demo123`): temple `temple1`, common user `user1`. Company: `admin` / `admin123`.

## Status
Prototype. Before a public launch it needs a real backend and database, secure password storage, a privacy policy, and verified temple data.
